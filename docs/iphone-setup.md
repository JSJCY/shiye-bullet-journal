# iPhone 安装与小组件

## 安装网页

1. 在 iPhone 的 Safari 打开自己部署或维护者提供的 HTTPS 地址。
2. 点击“账号与同步”。如果环境已开启邮箱注册，输入邮箱与密码，选择“注册邮箱账号”，输入收到的验证码。已有用户名也可登录。
3. 电脑和手机使用同一个账号。首次登录可选择“合并此设备旧笔记”，上传此前的访客记录。
4. Safari 分享菜单 → 添加到主屏幕。
5. 在线打开一次完成缓存后，可离线记笔记。恢复联网后，重新打开或回到前台会同步。

Safari 标签页与主屏幕 PWA 的数据存储可能不同；分别登录同一账号即可从云端拉取。云端同步已通过两个 HTTP 会话验证，实体 iPhone 和邮件实际收信仍需本人测试。

CloudBase 默认测试域名会显示平台访问提示；正式使用请绑定自己的自定义域名。

## Scriptable 小组件

1. 从 App Store 安装 Scriptable。
2. 在网页“账号与同步”面板下载 Scriptable 脚本，在 Scriptable 新建脚本并粘贴，或导入下载的拾页.js。
3. 在网页生成“只读凭据”并复制。凭据只显示一次。
4. 在 Scriptable 内运行脚本，输入自己的 HTTPS 小组件 API 地址、网页地址和只读凭据。网页下载的脚本会预填本次部署的地址，凭据保存到 Keychain。
5. 长按 iPhone 主屏幕 → 添加小组件 → Scriptable → 选择尺寸；编辑小组件，选择拾页脚本。

支持小、中、大尺寸，显示今日完成数、未完成任务、逾期情况与事件。点击小组件打开网页。Widget Parameter 可为不同账号指定不同配置名。

iOS 决定刷新时间；脚本建议约 15 分钟后刷新，但不能保证。网络失败会显示缓存及更新时间；凭据撤销返回 401 时清除缓存并提示重新配置。跨天缓存保留原日期。

## 更新与撤销

网页撤销凭据后，小组件的下一次请求会被拒绝。重新运行 Scriptable 脚本可更新配置。只读凭据允许读取当前账号的今日摘要，不能修改笔记；请勿公开。

迁移到自己的域名或另一套部署后，需要更新网页与 API 地址，并在对应账号重新生成凭据。
