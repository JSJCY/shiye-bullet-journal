# 清理误合并的旧笔记

请使用误点“合并此设备旧笔记”的同一浏览器和网站地址，并登录需要清理的账号。

1. 刷新网页，打开“账号与同步”。
2. 选择“清理误合并的旧笔记”。
3. 核对列表，可先下载完整备份，再只勾选误合并条目。
4. 点击“移到回收站”，等待同步状态显示已同步。

只移动选中的条目组。任务迁移历史保留，普通列表、搜索、跟进统计与小组件不会显示回收站记录。这是可恢复操作，不是永久删除。

误选时打开“账号与同步”→“回收站”，勾选并点击“恢复所选”。原内容、状态和完成时间保留。

旧版没有记录导入批次，候选列表按本机旧笔记 ID 匹配，可能包含之前已有或后来修改的记录。不能视为这次误合并的精确批次；默认不勾选任何记录。

没有找到匹配项时，确认使用了误操作时的同一设备、浏览器及网站地址。也可通过单条记录“···”→“移到回收站”清理。

新的旧笔记合并入口先预览、勾选，再由本人确认。同 ID 的回收站记录不会因重复合并重新出现。

若记录在预览期间变化，或其大小/历史无法保证完整恢复，会拒绝操作，需重新核对或先备份。离线操作会暂存，联网后同步，以面板中的同步状态为准。
