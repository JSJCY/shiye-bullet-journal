# 验收范围

日期：2026-10-13，Asia/Shanghai。

## 当前版本的验证

- 本地 32/32 测试通过，涵盖符号、任务迁移、时间、事件、IndexedDB、冲突、PostgreSQL 存储与部署配置保护；23 个模块及 Scriptable 语法检查通过。
- PostgreSQL 17.11 云环境已实际应用迁移，专用表启用 RLS，RPC 使用 SECURITY INVOKER。
- journal 与 journal-widget 实际部署为 Active。Event 函数内联 SDK 后正常执行，缺少用户身份的调用被拒绝。
- 已发布的 17 个静态文件经过独立 HTTPS SHA-256 校验。
- 13 项真实云端检查通过：正常登录、可信身份、幂等、两个会话新增同步、完成同步、完成时间一致、旧版本冲突拒绝、账号隔离、伪造 owner 拒绝、小组件读取、写入拒绝、独立凭据不可调用同步、撤销后 401。
- 云端测试只使用本次随机创建的两个临时账号。测试后账号及记录已删除，数据库读回为零，旧账号无法登录，临时凭据文件已删除。
- 云端配置读回邮箱登录与平台邮件代发已开启；实际邮件收信未测试。
- 本地两个独立 origin 的离线重开、账号恢复、待同步队列恢复和联网拉取通过。
- 本地 390×844 视口无横向溢出，输入框 16px。

发布整理新增环境配置保护测试，确保新用户必须选择自己的环境，并拒绝混用部署缓存、含凭据的 URL 和不支持的部署路径。

从暂存文件导出的干净副本已验证 npm ci（0 个已知漏洞）、首次 SDK/图标生成、本地 HTML 与资产 HTTP 读取，以及另一个示例环境的云端构建；验证没有修改线上部署。

## 尚未验证与限制

- 实体 iPhone Safari 主屏幕安装、系统离线行为及 Scriptable 实机渲染。
- 实际邮箱收信与邮箱验证码注册流程。
- 线上浏览器穿过腾讯云测试域名访问提示后的渲染，以及真实云模式下的浏览器离线恢复和冲突草稿操作。
- 没有删除/回收站和系统事件推送。使用每 30 秒前台轮询，未接入 PostgreSQL Realtime。
- Scriptable 的刷新由 iOS 调度。

CloudBase 部署验收与新环境部署成功是两件独立的事。部署者应按自己的域名、权限与账号重复端到端检查。
